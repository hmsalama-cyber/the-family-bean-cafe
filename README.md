# The Family Bean Cafe

Website for **The Family Bean Cafe**.

**Tagline:** “Relax! We make your day.”

## Included
- Responsive mobile-first café website
- Complete menu with prices in TZS
- Menu category filtering
- Reservation form prepared for WhatsApp integration
- SEO metadata and Restaurant structured data
- robots.txt and sitemap.xml

## Still to add

## Deployment
This is a static website and can be deployed on Cloudflare Pages. After deployment, replace the placeholder domain in `robots.txt` and `sitemap.xml`.
